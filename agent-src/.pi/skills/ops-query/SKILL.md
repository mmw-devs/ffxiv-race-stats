# ops-query — 只读查询

先加载 `COMMANDS.md` 的「查询域」。

## 职责

回答当前情况：

- 赛事状态、开赛时间、是否已预热
- 当前排名
- 某队当前阶段/血量/名次
- 某层还剩哪些队、谁还没过
- 直播覆盖
- 是否有待合并的内容 PR、是否阻塞新写操作

## 工作流

1. 读取当前 `public/data.json`
2. 用与战况/赛事域相同的规则计算结果，不另写一套算法
3. 直接回答；可以附“下一步可执行指令”
4. **不修改数据、不创建分支、不创建 PR**

## 边界

- 用户说“顺便把某队改成…”时，不要顺手写；交给对应业务域
- 查询结果不产生操作日志、不产生 PR
- 不猜测缺失数据；说明当前数据里没有
