# ops-roster — 名单与直播

先加载 `.pi/commands.md` 的「名单域」；本 skill 只负责流程与话术。

## 职责边界

负责：

- 加队、批量加队、删队/退赛
- 改队名、区服
- 设置 8 人阵容
- 选手直播开关

不负责：

- 比赛进度（新队只给初始状态，之后交给战况）
- 名次规则本身（调用战况域的名次规则）
- 速报/公告（交给发布）

## 工作流

### 1. 解析

| 指令 | 必需参数 |
|---|---|
| 加队 / 批量加队 | 队名、区服；可选阵容 |
| 删队 / 退赛 | 队名或队伍 id |
| 改队名 / 区服 | 目标队伍、新值 |
| 设置阵容 | 目标队伍、8 人职业顺序 |
| 直播开关 | 目标队伍/选手、开播链接或下播 |

### 2. 读取并校验

按 `.pi/commands.md` 的名单前置条件检查：

- 加队：名次接在最后；初始阶段/血量符合规则；阵容完整
- 删队：删除后名次连续；至少保留 1 队
- 阵容：人数、位置顺序、职业与位置对应（具体值域以 validator 为准）
- 直播：平台与链接合法；开播必须有链接

### 3. 名次处理

- 加队：接在当前最后一名之后
- 删队：删除后重排名次
- 如果加减队导致名次与进度冲突，交给战况域调整名次，不能硬写

### 4. 预览

展示：

- 队伍数量变化
- 名次变化（加队/删队时）
- 阵容逐位变化
- 直播开关变化
- 影响标记（删队可能触发 `podium-change` / `final-standings-change`）

### 5. 确认并提交

- 加队/删队/阵容：短语确认（如「确认名单调整」）
- 改队名/区服、直播开关：普通确认
- 记录变更，调 `ops-submit`，级别 **L2**

## 拒绝模板

```
【拒绝】加队缺少阵容
下一步：请提供 8 人职业顺序（2T/2H/4DPS），或先只创建队伍、再单独发「设置阵容」。
```

- 最后一队不允许删除
- 比赛开始后加队，只能从第一层 P1 开始、排在最后
