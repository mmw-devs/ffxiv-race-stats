# ops-publish — 对外发布

先加载 `COMMANDS.md` 的「发布域」；本 skill 只负责流程与话术。

## 职责边界

负责：

- 速报（news）
- 公告（notices）
- 赞助（sponsors）
- 转播台（broadcasters）

不负责：

- 比赛数据、开赛/结束
- 站点文案/规则/SEO/媒体

## 速报与公告的区别

| | 速报 | 公告 |
|---|---|---|
| 字段 | `news` | `notices` |
| 用途 | 比赛时间线 | 赛事公告板 |
| 赛前 | **不可用**（时间不得早于开赛） | 可用 |
| 风格 | 简洁陈述句 | 说明性文字 |

如果运营在赛前说“发个公告”，写入 `notices`，不要写 `news`。

## 工作流

### 1. 识别类型

- “速报/快讯/战报” → news
- “公告/通知/说明” → notices
- “赞助/合作方” → sponsors
- “转播台/合作直播间” → broadcasters

### 2. 校验

按 `COMMANDS.md` 与 validator：

- 速报：当前必须是 live 或 ended；时间/长度/标点合法
- 公告：条数与长度合法、不重复
- 赞助：名称/描述合法
- 转播台：平台/域名合法、名称唯一

赛前要求发速报时，拒绝并建议改用公告。

### 3. 预览

展示旧值 → 新值；数组类展示“新增/修改/删除”的完整条目，不只给摘要。

### 4. 确认并提交

- 普通确认「确认」
- 记录变更，调 `ops-submit`，传 `command` 与变更；级别由适配器查契约

## 拒绝模板

```
【拒绝】现在是赛前，速报时间不能早于开赛时间。
下一步：改用「公告」发布；开赛后再发速报。
```
