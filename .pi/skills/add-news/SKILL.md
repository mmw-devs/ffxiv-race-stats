# add-news

## 前置条件

在开发模式（/dev）下，此 Skill 不可用。如触发时处于开发模式，回复：
"当前开发模式（/dev），无法操作 data.json。请 /ops 返回运营模式后操作。"

## 输入

运营自然语言，例如：
- "发一条速报：Neverland 世界首杀，用时 38 小时"
- "公告：服务器维护，明天下午 2 点恢复"

## 工作流

### Step 1: 提取信息

从运营输入中提取：
- `title`：简洁标题（≤50 字）
- `urgent`：是否标记为紧急（首杀/重大事件）
- `time`：自动生成当前时间

### Step 2: 确认

向运营确认：
```
"确认添加速报：
  标题：[提取的标题]
  时间：2026-06-15 18:30
  紧急：是/否
是否发布？"
```

### Step 3: 修改

在 `data.json` 的 `news[]` 数组头部插入新条目。
- `id`：基于已有最大 id + 1（如现有 `n1`~`n5`，新 id 为 `n6`）
- `time`：当前时间，格式 `YYYY-MM-DD HH:mm`

### Step 4: 提交

修改完成后，调用 **`content-pr` Skill** 完成分支创建、PR 提交和后续合并流程。
